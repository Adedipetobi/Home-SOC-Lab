# Home SOC Lab

## Objective

This project demonstrates the design and implementation of a Home Security Operations Center (SOC) using Splunk Enterprise, Sysmon, and Windows Event Logs.

The goal is to simulate real-world cyber attacks, collect endpoint logs, detect malicious activity, investigate security incidents, and document findings using industry-standard tools and techniques.

---

- Kali Linux ARM
- VMware Fusion Pro
