# Kali Linux Installation

## Objective
Install Kali Linux ARM in VMware Fusion on an Apple Silicon Mac to simulate attacker activity in a Home SOC Lab.

## Environment

Host:
- macOS
- VMware Fusion

Guest:
- Kali Linux
- XFCE Desktop
- ARM64

## Installation Steps

- Downloaded Kali ARM ISO
- Created new VMware Fusion VM
- Allocated CPU and RAM
- Installed Kali Linux
- Configured disk partitions
- Installed VMware Tools
- Verified clipboard sharing
- Verified automatic display resizing
